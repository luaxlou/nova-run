# Nova Run Local Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `nova run [app|all]` as an Agent-independent foreground runner for local development commands declared directly in `nova.yaml`.

**Architecture:** Extend project configuration with a deployment-independent `run` resolution path, then execute resolved commands through a focused `internal/localrun` process supervisor. Route `nova run` before remote runtime bootstrapping so local execution never needs an Endpoint or Token, while retaining all existing deployment validation.

**Tech Stack:** Go 1.24.5, `gopkg.in/yaml.v3`, standard-library `os/exec`, Unix process groups and signals, Go `testing`.

**Spec:** `docs/nova-run-spec.md`

## Global Constraints

- `nova run` must not read or validate Nova Agent Endpoint, Token, or connectivity.
- Configuration is exactly `run: <single shell command>` at the top level or under `apps.<selector>`; do not add env, cwd, dependency, watch, restart, or logging configuration.
- Execute commands with `sh -lc` in the directory containing `nova.yaml`, inheriting the caller environment.
- `nova run` selects the default app, `nova run <selector>` selects one child app, and `nova run all` selects all child apps in YAML declaration order.
- Validate every selected command before starting any process; missing commands are errors, never silent skips.
- A first process exit or user signal terminates the remaining process groups; force-kill them after exactly 3 seconds.
- Preserve existing `deploy`, remote lifecycle, artifact, systemd, and journald behavior and validation.
- Supported release targets remain Linux and macOS on amd64 and arm64; add no external dependency.

## File Structure

- Modify `internal/project/config.go`: add raw `run` fields and deployment-independent loading/resolution functions.
- Modify `internal/project/config_test.go`: cover local-only configuration, inheritance, ordering, preflight errors, and unchanged deploy validation.
- Create `internal/localrun/runner.go`: own foreground orchestration, streams, exit results, cancellation, and grace-period cleanup.
- Create `internal/localrun/process_unix.go`: isolate Linux/macOS process-group setup, TERM, and KILL operations.
- Create `internal/localrun/runner_test.go`: exercise stdio, concurrency, exit codes, cancellation, and forced cleanup with real shell children.
- Modify `cmd/nova/main.go`: route `run` before Agent bootstrap, resolve local targets, and map runner errors to CLI exit codes.
- Create `cmd/nova/run_test.go`: cover selector argument handling, local config loading, error messages, and Agent-bootstrap bypass.
- Modify `README.md`: document the new command, configuration field, examples, and local/remote boundary.

- [ ] **Step 4: Implement Unix process-group primitives**

In `process_unix.go`, restrict the file to release platforms and make each shell command its own group so grandchildren are cleaned up:

```go
//go:build linux || darwin

package localrun

import (
	"os"
	"os/exec"
	"syscall"
)

func prepareProcess(cmd *exec.Cmd) {
	cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}
}

func terminateProcess(cmd *exec.Cmd) error {
	return syscall.Kill(-cmd.Process.Pid, syscall.SIGTERM)
}

func killProcess(cmd *exec.Cmd) error {
	return syscall.Kill(-cmd.Process.Pid, syscall.SIGKILL)
}

func terminationSignals() []os.Signal {
	return []os.Signal{os.Interrupt, syscall.SIGTERM}
}
```

Ignore `ESRCH` during cleanup because it means the group has already exited; preserve other signal errors for diagnostic wrapping.

- [ ] **Step 5: Implement the runner orchestration**

In `runner.go`, validate a non-empty command list, non-empty names and commands, non-nil stdout/stderr, and a positive grace period before starting anything. Build every `exec.Command("sh", "-lc", spec.ShellCommand)` with `Dir = dir`, direct stdout/stderr, and stdin only when there is exactly one command. Call `prepareProcess` before `Start`.

Define exit errors exactly once:

```go
type ExitError struct {
	Name    string
	Command string
	Code    int
	Err     error
}

func (e *ExitError) Error() string {
	return fmt.Sprintf("%s command %q exited with code %d: %v", e.Name, e.Command, e.Code, e.Err)
}
func (e *ExitError) Unwrap() error { return e.Err }
func (e *ExitError) ExitCode() int { return e.Code }
```

Start all children before waiting; if any `Start` fails, terminate and reap those already started and return an error containing the name, command, and original error. Print `[name] $ command` before each multi-process start. Wait through one buffered result channel carrying `{childIndex, err}`. On the first result, or on cancellation from `signal.NotifyContext(ctx, terminationSignals()...)`, TERM every still-running process group, wait at most `gracePeriod`, KILL the remaining groups, and reap every `cmd.Wait` result exactly once.

Map `*exec.ExitError.ExitCode()` into `ExitError`. Return `nil` for a first clean exit, the first child exit code for a child failure, and `ExitError{Code: 130, Err: context.Canceled}` for user/parent cancellation. Cleanup errors may be joined to the primary result with `errors.Join`, but must not replace its exit code.

- [ ] **Step 4: Add the local command adapter**

Implement `runConfiguredLocal` with an exact 0-or-1 selector rule, print `project config: <path>`, resolve all targets before adapting any of them, and call the runner with a 3-second grace period:

```go
func runConfiguredLocal(ctx context.Context, dir string, args []string, streams localrun.Streams) error {
	if len(args) > 1 {
		return fmt.Errorf("expected zero or one configured app selector")
	}
	cfg, path, err := project.LoadForRun(dir)
	if err != nil {
		return err
	}
	fmt.Fprintf(streams.Stdout, "project config: %s\n", path)
	selector := ""
	if len(args) == 1 {
		selector = args[0]
	}
	var targets []project.RunTarget
	if selector == "all" {
		targets, err = project.ResolveAllRuns(cfg)
	} else {
		var target project.RunTarget
		target, err = project.ResolveRun(cfg, selector)
		targets = []project.RunTarget{target}
	}
	if err != nil {
		return err
	}
	commands := make([]localrun.Command, 0, len(targets))
	for _, target := range targets {
		commands = append(commands, localrun.Command{Name: target.Name, ShellCommand: target.Command})
	}
	return localrun.Run(ctx, commands, filepath.Dir(path), streams, 3*time.Second)
}
```

Only append the single target after checking its resolution error, so a failed resolution cannot create a zero-value command.
